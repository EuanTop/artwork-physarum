## 生长之间 · Physarum

[Open the live artwork](https://euantop.github.io/artwork-physarum/)

A particle artwork driven by aggregated scan measurements. Move the pointer to guide growth, click to add nutrients, or change the observation time. Scan data by Kyle and Iris Harrington, [Physarum experiment 001, dish 0](https://zenodo.org/records/22868368), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Measurements are aggregated for an artistic simulation.

Build from the included source and release data with Node.js: `npm install`, then `npm run build`.
